THE PRACTICAL GUIDE / 01

NFC는 이렇게 사용해요.

휴대폰에서 Chrome 브라우저로 HTTPS 주소를 열고 NFC를 켠 다음, 기록하기 버튼을 눌러 태그를 폰 뒷면에 대세요. 기존 태그 내용은 덮어써질 수 있어요.

01

명함을 만들거나 태그에 기록할 주소·메모를 선택

02

용량 확인 후 기록 버튼을 누르고 브라우저 권한 허용

03

휴대폰의 NFC 영역에 스티커를 대고 완료 메시지 확인

Web NFC가 지원되지 않거나 태그가 잠겨 있으면 기록할 수 없어요. 용량 표시는 안전 여유를 포함한 추정치이며, 실제 태그의 메모리·NDEF 인코딩에 따라 달라집니다. 명함 링크와 NFC 스티커는 받은 사람이 누구나 열 수 있으므로 공개해도 되는 정보만 사용하세요.
